# 币安 Alpha 助手

一款 Chrome 浏览器扩展，帮助您在币安 Alpha 交易页面快速填充限价订单参数。

## ✨ 功能特性

- **智能限价计算** - 根据当前价格和价格步长，自动计算买入/卖出限价
- **价格偏移设置** - 可调节价格偏移 Ticks（1-20），灵活控制限价幅度
- **数量预设管理** - 支持自定义多个交易数量预设，快速切换
- **一键自动填充** - 同时填充买入价格、卖出价格和交易数量
- **自动买入模式** - 可选开启，填充后自动点击买入按钮（谨慎使用）
- **双语支持** - 支持中文/英文界面切换
- **可拖拽悬浮窗** - 界面可自由拖动，不遮挡交易视图

## 📦 安装方法

### 从源码构建

1. 克隆仓库
   ```bash
   git clone https://github.com/your-username/binance_alpha_tool.git
   cd binance_alpha_tool
   ```

2. 安装依赖
   ```bash
   pnpm install
   ```

3. 构建扩展
   ```bash
   pnpm build
   ```

4. 在 Chrome 中加载扩展
   - 打开 Chrome，进入 `chrome://extensions/`
   - 开启「开发者模式」
   - 点击「加载已解压的扩展程序」
   - 选择项目中的 `dist` 文件夹

## 🚀 使用方法

1. 打开币安 Alpha 交易页面
2. 点击浏览器工具栏中的扩展图标，打开悬浮窗
3. **前置条件**：确保已勾选页面上的「反向订单」选项
4. 调整参数：
   - **价格偏移 (Ticks)** - 设置限价与当前价的偏移量
   - **数量预设** - 选择或添加交易数量
5. 点击「自动填充」按钮

### 计算公式

```
买入限价 = 当前价格 + (价格步长 × 偏移Ticks)
卖出限价 = 当前价格 - (价格步长 × 偏移Ticks)
```

## ⚠️ 注意事项

- 使用前请确保已启用「反向订单」功能
- 「自动买入」模式会在填充后立即执行买入操作，请谨慎使用
- 本工具仅作为辅助，交易决策请自行判断
- 不对任何交易损失负责
